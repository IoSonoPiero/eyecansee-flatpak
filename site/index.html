EyeCanSee Flatpak

Viewer, manager and editor for photos, videos, 3D models and CAD drawings, as a Flatpak for every Linux distribution, Fedora Atomic included.

Install with your software center

Your browser downloads a small file: open it and your software center offers EyeCanSee. The runtime comes from Flathub, added for you if it is missing.
Flatpak not set up yet? Follow the guide for your distribution first.

Install

From a terminal

flatpak install https://flatpak.montinaro.info/eyecansee.flatpakref

Updates come with flatpak update or your software center, like any other Flatpak; EyeCanSee does not check for updates by itself.

Other ways to install: Windows (Microsoft Store, installer or zip), Fedora Workstation (COPR) and the AppImage.

Good to know

  • Signed by the developer: every version is signed with the key 11F7D1A7D8D356D2FDE8AC47D54E92F7B64C427D, whose public part is inside the .flatpakref and .flatpakrepo files and in eyecansee-flatpak.gpg.
  • H.264 and HEVC video conversion needs the org.freedesktop.Platform.codecs-extra extension, which Flatpak installs together with the runtime; AV1, VP9 and the audio formats work without it.
  • Its own settings: the list of servers starts empty, apart from the AppImage's and the Fedora package's. The SSH server keys you trusted (~/.ssh/known_hosts) are shared, as with ssh.
  • With the AppImage or the Fedora package installed too, the menu shows two EyeCanSee entries.
